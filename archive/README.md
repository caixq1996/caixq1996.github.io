# Archive

This directory preserves files that are no longer part of the Hugo deployment.

- `legacy-site/` contains generated snapshots, earlier homepage designs, standalone experiments, and obsolete configuration or asset bundles.
- `cv-build/` contains historical LaTeX intermediates and vendored package backups.

The archive is intentionally outside `static/` and is therefore not published by Hugo. Active site behavior must be changed in `content/`, `layouts/`, `static/`, `CV/en_caixq_cv.pdf`, or `hugo.yaml`.
