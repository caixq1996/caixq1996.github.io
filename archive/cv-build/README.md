# Archived CV Build Material

- `artifacts/` contains previously tracked LaTeX auxiliary, log, recorder, and SyncTeX files.
- `vendor/` contains historical local package bundles that are not required by the current TinyTeX build.

The active CV files remain in `CV/`: the LaTeX sources, `lastpage.sty`, and the published PDF. New intermediate files in `CV/` are ignored to keep the active tree clean.
