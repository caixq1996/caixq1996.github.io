# Legacy Site Files

Historical website material is grouped by purpose:

- `generated/`: formerly tracked site output, including the last root `index.html` snapshot and generated section pages.
- `snapshots/`: named pre-Hugo pages and timestamped homepage backups.
- `design-iterations/`: Gemini-assisted homepage variants.
- `standalone/`: nutrition experiments and stylesheets used only by retired pages.
- `assets/`: obsolete packaged assets.
- `config/`: configuration from the retired Jekyll/static workflow.

These files are preserved for comparison only. The active site is generated from the repository's Hugo source.
